# 🤖 机器学习算法教学平台

一个交互式的机器学习算法教学平台，旨在通过可视化和互动演示帮助学习者理解各种机器学习算法的原理和应用。

## 📚 项目简介

本项目提供了一系列精心设计的机器学习算法教学网页，涵盖回归、分类和聚类三大核心算法类别。每个教学页面都包含直观的可视化展示、交互式演示和通俗易懂的原理解释，适合机器学习初学者和希望深入理解算法原理的学习者使用。

## 🎯 核心功能

### 算法导览页面
提供机器学习算法的整体分类和导航，清晰展示回归、分类和聚类三大类算法的关系和应用场景。

### 交互式算法教学
每个算法都有独立的教学页面，包含：
- 算法原理的直观解释
- 可视化的算法流程展示
- 交互式参数调整
- 实时结果展示和反馈

### 图像分类训练平台
一个专业级的图像分类模型训练和预测平台，支持：
- 多类别图像训练
- 实时预测功能
- 专业级AI模型应用

## 🛠️ 技术栈

### 前端技术
- **HTML5/CSS3**：页面结构和样式
- **JavaScript**：交互逻辑和算法实现
- **D3.js**：数据可视化和流程图绘制

### 机器学习框架
- **TensorFlow.js** (`tf.min.js`)：在浏览器中运行机器学习模型

### 第三方库
- **Chart.js**：用于创建各种统计图表
- **Three.js**：3D场景渲染
- **OrbitControls.js**：Three.js的轨道控制器，提供3D交互
- **MobileNet**：预训练的图像分类模型

## 📊 关键JS库文件说明

| 文件 | 版本/类型 | 用途 |
|------|-----------|------|
| `chart.js` | Chart.js v4.5.0 | 用于绘制各类统计图表，展示数据分布和算法结果 |
| `mobilenet.min.js` | MobileNet模型 | 提供预训练的图像分类能力，支持图像识别教学 |
| `OrbitControls.js` | Three.js控制器 | 为Three.js场景提供旋转、缩放和平移控制，增强3D交互体验 |
| `tf.min.js` | TensorFlow.js | 核心机器学习框架，支持在浏览器中训练和运行模型 |
| `three.min.js` | Three.js v128 | 3D渲染引擎，用于创建复杂的3D可视化效果 |

## 🚀 如何使用

1. 克隆或下载本项目到本地
2. 在浏览器中打开根目录下的`index.html`或`machine-learning/machine-learning-index.html`
3. 从算法导览页面选择感兴趣的算法进行学习
4. 通过调整参数、查看可视化效果和阅读说明来理解算法原理
5. 使用图像分类训练平台体验AI模型的训练和预测过程
